# БорИскра — Welding Work Tracker

A Russian-language welding work tracker built as an Expo React Native app, deployable as a browser-based web application (React Native Web).

## Architecture

### Frontend
- **Framework**: Expo (React Native Web static export)
- **State**: Firebase Realtime Database (iskra-ppm, europe-west1)
- **UI**: Dark navy theme (#0B1120), orange accent (#F97316), Rubik font
- **Icons**: Ionicons from @expo/vector-icons (no emoji)
- **Build output**: `dist/` folder (generated by `npx expo export --platform web`)

### Web Server
- **File**: `scripts/web-server.js`
- **Port**: 5000 (via `process.env.PORT`, which is `PORT=5000` in Replit env)
- **Purpose**: Serves the `dist/` static export as a SPA (serves index.html for all routes)

### No Backend Required
The app uses Firebase directly from the client. The Express server in `server/` has no API routes (routes.ts is empty). The web server just serves static files.

## Development Workflow

1. **Start the server**: Press the **Run** button in Replit. This starts `node scripts/web-server.js` on port 5000.
2. **Rebuild the app**: Run `npx expo export --platform web --output-dir dist` to rebuild after frontend changes.
3. **View the app**: Use the Replit preview pane or the external dev URL.

## Deployment

For production deployment, the `[deployment]` section in `.replit` uses:
```
run = ["npm", "run", "server:prod"]
```
This starts the compiled Express server which serves the `dist/` folder.

## Features

### Roles
- **Сварщик (Welder)**: Login with name only, can view/add work records and chat
- **Руководитель (Manager)**: Login with name + PIN (default: 1234), full access + admin features

### Tabs (after login)
1. **Записи (Records)**: Work records management with Excel export (managers can export all records)
2. **Чат (Chat)**: Real-time team chat via Firebase
3. **Продукция (Products)**: Products management with Excel import/export

### Excel Features
- Managers can export records to Excel (.xlsx)
- Managers can export/import products to/from Excel (.xlsx)
- Import detects duplicates by article number

## Key Files
- `app/_layout.tsx` - Root layout with font loading (handles fontError for graceful degradation)
- `app/index.tsx` - Login screen
- `app/(tabs)/records.tsx` - Records tab
- `app/(tabs)/chat.tsx` - Chat tab (paddingBottom: 84 on web for tab bar clearance)
- `app/(tabs)/products.tsx` - Products tab
- `context/AppContext.tsx` - Global state + Firebase (user, records, products, chat)
- `utils/excel.ts` - Excel import/export utilities
- `scripts/web-server.js` - Static web server for the built app

## Firebase Config
- Project: iskra-ppm (europe-west1 region)
- Database: Realtime Database
- Collections: `/records`, `/chatMessages`, `/products`

## Important Notes
- Tab bar is 84px height on web (absolute-positioned), chat uses paddingBottom: 84
- Font loading uses `fontError` fallback so app renders even if Google Fonts CDN fails
- `SplashScreen.hideAsync()` is called when `fontsLoaded || fontError`
- Manager PIN default: 1234
